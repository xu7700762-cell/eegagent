# VRMS 原始波形推理

## 工具与分类

vrms.raw_recording从原始Trigger波形确定任务片段及完整性。vrms.raw_model将同一原始EEG重新处理并编码，执行冻结的VRMS整路径MIL、八路数值工具及融合权重。没有读取目标问卷、当前被试标签、预测表或冻结编码特征缓存。数值工具内的训练期拟合参数保留在本地模型内部，不作为被试答案交给语言Agent或RAG。已知本地被试使用将其排除在拟合之外的对应模型；新上传的兼容EDF使用预先固定的部署权重，不将此输出宣称为已验证的外部泛化性能。

真实API模式以GPT工具Agent返回的离散High/Low作为最终分类。GPT通过实际Responses函数调用读取八路工具与corrective_evidence，按工具证据及内部验证判断；模型与组合分数保留在本地中间记录中。网页回答给出GPT最终类别及工具依据。工具在GPT请求前从原始EEG重新计算，函数调用读取本次结果，不宣称按需才计算波形。GPT只给定性置信度，不产生新概率。High/Low的训练任务是整路径问卷高低类别，推理不读取当前问卷。GPT调用、格式或工具引用校验失败时不发布GPT类别。路径缺结束标记、合格窗不足或覆盖率不足时不分类，其余已完成分类逐条报告。离线VRMSModel调用不能称为真实GPT判断。

记录开始已处于VR暴露环境，本入口不发送开头参考波形，不计算相对该参考的谱变化。数值工具沿用训练定义的无参考分支：相对变化特征为零并将参考可用标记置零；训练拟合的归一化与模型权重保持冻结。路径内前后差仍取同一路径真实窗口。历史使用开头参考的融合结果及ACC不能视为本无参考协议的验收结果。

## 高类时间的位置

工具按原始时间排列已分类完整路径，返回第一条GPT最终判为High路径的起止时间。该判定使用整条路径的数据，最早在该路径结束后形成，不能据此定位路径内部真实症状首次发生的秒数。全部已分类路径均为Low时报告未检出高类，不补造高类起点。当前全路径评价的分母、失败补跑及适用范围见docs/PROTOCOL.md；ACC不能作为本条查询的成功保证。
